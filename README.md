\# qa-yurchenko\_m



Навчальний репозиторій з практичними роботами з QA: тест-кейси, баг-репорти, чек-лісти, дослідження селекторів (CSS/XPath), та інші матеріали курсу.



\## Структура



\- `docs/` — тест-плани, чек-лісти, звіти

\- `test-cases/` — тест-кейси у повному форматі

\- `.gitignore` — виключені службові файли й секрети



\## Стек / інструменти



\- Ручне тестування, дослідницьке тестування

\- DevTools (Network, Application, Console)

\- CSS-селектори, XPath

\- Jira / Trello для баг-репортів
